# Changelog

All notable changes to Sharper will be documented in this file.

## 0.1.0

- Add local CSV and optional single-sheet XLSX loading, schema inference,
  DataFrame summaries, and deterministic data-quality reporting.
- Add non-target and target relationship analysis, bounded feature suggestions,
  safe stateless derivations, and static analytical plots.
- Add split-first classification and regression baselines with holdout-only
  evaluation, plus target analysis without model training.
- Add the complete Python workflow, Markdown/HTML report-and-PNG-assets bundles,
  and the `sharper analyze` CLI.
- Add release-readiness documentation, examples, distribution validation, and CI
  configuration for the v0.1 package.
